Ingestion and calculation

The imported CSV already contains reduced Cash Subtotals, Tax, Tip and Order Total; these values are used as provided. Card/Credit Convenience Fee = source Processing Fee; Cash Convenience Fee = the entered flat amount per completed transaction, replacing the source Cash Processing Fee. A refunded Cash row reverses one flat fee. Amount Charged = Order Total + Convenience Fee + Service Fee. Export replaces Processing Fee and Amount Charged with Convenience Fee and the recalculated Amount Charged. The original file stays unchanged.
